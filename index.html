Test du coffre

Cette page vérifie que Face ID ou Touch ID peut fermer et rouvrir un coffre. Elle ne parle à aucun serveur et rien de réel n'est protégé ici. Version 2.

    Étape 1 : crée un coffre de test

    Ton appareil va te demander Face ID, Touch ID ou ton code.

    Étape 2 : recharge la page, puis rouvre le coffre

    Si le trésor réapparaît, le coffre fonctionne sur cet appareil.

    Étape 3 : essaie sur un autre appareil

    Sur un autre appareil relié au même compte Apple ou Google, ouvre cette même adresse et touche ce bouton. Choisis la passkey qui porte le même nom. Le numéro de passkey et le code de contrôle doivent être identiques à ceux du premier appareil.

    Résultat à envoyer

    Copie ce texte et envoie-le dans la conversation.

    Recommencer

    Efface le test de cette page. La passkey de test reste dans tes mots de passe : tu peux la supprimer là-bas.
